## Getting Started

1. Run `npm install`
2. Run `npm run dev`

## Testing & quality gates

Linting, type checking, tests (with coverage) and the build run on every push/PR and every
deployment. Run them locally with:

```
npm run lint         # ESLint
npm run typecheck    # tsc --noEmit
npm run test:run     # Vitest (once)
npm run test:coverage # Vitest + coverage
npm run build        # production build
```

See [TESTING.md](./TESTING.md) for the full stack, coverage thresholds, CI, and how deployments are
gated.
